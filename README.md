# Sarah Nahar Chowdhury — Professional Portfolio

Complete static website migrated from the existing portfolio, preserving its design, content, research illustrations, photographs, institutional logos, publication lists, filters, expandable lists, and CV download.

## Hosting

In this repository, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/ (root)**, then save.

The website uses relative asset paths and requires no build step, packages, API keys, or backend.

## Editing and preview

Edit `index.html` for page content and styles. Image assets and the downloadable CV are included alongside it. Preview locally with `python3 -m http.server 8000` and open `http://localhost:8000`.

The JSON source notes record provenance for the illustrations and logos. The original Sites hosting configuration is intentionally excluded because it is specific to the previous host.
